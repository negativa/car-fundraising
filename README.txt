Сайт збору на автомобіль для служіння
=====================================

Структура:
- index.html
- css/style.css
- js/main.js
- assets/

Що змінено:
1. Збір рахується у доларах США, а не в гривнях.
2. Інтерактивна логіка переписана на Alpine.js.
3. Банка Mono активна за замовчуванням у табах реквізитів.
4. Прогрес зчитується з Google Таблиці у форматі:

дата,сума
22.05.2026,100
23.05.2026,250

Як налаштувати суму збору:
- Відкрийте js/main.js
- Змініть goalAmount, наприклад:
  goalAmount: 25000,

Як підключити Google Таблицю:
- Таблиця має бути доступна для перегляду.
- Вона має мати 2 стовпці: дата, сума.
- Суми вносьте у доларах, наприклад 100 або 250.50.
- У js/main.js замініть googleSheetId на ID вашої таблиці.

Alpine.js:
- Підключений через CDN у index.html.
- Для роботи на опублікованому сайті потрібен доступ до інтернету.

Перед публікацією:
- Замініть реквізити у вкладках Mono, PayPal, SEPA, SWIFT на реальні.
- За потреби замініть фото у папці assets.


Оновлення: всі фото автомобілів відкриваються в модальному вікні. Закрити можна кнопкою ×, кліком поза фото або клавішею Esc.

Сторінка збору на автомобіль для служіння
=========================================

Структура:
- index.html
- css/style.css
- js/main.js
- assets/

Що є в цій версії:
1. Світла тема за замовчуванням + перемикач світлої/темної теми в header.
2. Header з меню, як у попередньому варіанті: Прогрес, Донати, Навіщо, Фото, Підтримати.
3. Велике головне фото нового автомобіля.
4. На мобільній версії блоки прогресу, останніх донатів і реквізитів ідуть одразу після головного фото.
5. Історія донатів підтягується з Google Таблиці.
6. Основні тексти сторінки можуть підтягуватися з Google Таблиці.
7. Усі фото відкриваються у модальному вікні.
8. Логіка працює через Alpine.js.

Google Таблиця
==============
У файлі js/main.js змініть налаштування:

const FUNDRAISING_CONFIG = {
  goalAmount: 20000,
  googleSheetId: 'ID_ВАШОЇ_ТАБЛИЦІ',
  supportersSheetName: 'Supporters',
  contentSheetName: 'Опис',
};

Вкладка Supporters
------------------
Формат колонок:

Дата | Сума, $ | платіжна система | Країна

Приклад:
05.05.2026 | 80 | PayPal | Друзі з України
07.05.2026 | 116 | Credit card | Друзі зі Словаччини

Суми рахуються як долари США.

Вкладка Опис
------------
Підтримується формат, як на вашому скріншоті:

A: ключ      B: текст                       C: ключ      D: текст
header      Надійний транспорт...          Paragraph   Старий мікроавтобус...
title       Для чого потрібен...           title       Чому старий вже небезпечний
desc        Надійний транспорт...          desc        Стан авто вже...
item        Підвіз дітей...                 item        Критична корозія...
item        Поїздки команди...              item        Періодичні поломки...

Також можна використовувати прямі ключі:
- heroTitle
- mainTitle
- heroParagraph
- eyebrow
- oldPhotoCaption
- targetPhotoCaption
- useTitle
- useDesc
- dangerTitle
- dangerDesc

==========

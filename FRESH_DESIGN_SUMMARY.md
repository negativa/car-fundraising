# Резюме гілки fresh-design

## 🎨 Огляд змін

Гілка **fresh-design** містить комплексний редизайн сторінки збору з нео-морфним світлим дизайном, темною темою, мультимовною підтримкою та покращеною архітектурою даних.

---

## 🔄 Ключові зміни

### 1. **Архітектура та структура**

#### Старе (main):
- Конфіг, контент і логіка потяг в одному файлі `js/main.js`
- Дані завантажуються прямо з Google Sheets API
- CSV парсинг вбудований в основний файл
- Структура на основі боків (left-stack, right-stack)

#### Нове (fresh-design):
- **Чіста архітектура**: Функція `fundraiserPage()` повертає об'єкт з локалізацією та логікою
- **Локальне сховище**: Використання `localStorage` для збереження мови та теми
- **Делегований парсинг**: Окремі методи для `parseContent()`, `parseDonations()`, `fetchSheet()`
- **Таблицы Google Sheets Query**: Використання `gviz/tq` для прямого запиту замість CSV

```css

/* vs. старого чорного мінімалізму */

--blue: #3283d5;      /* Синій */
```

### 3. **Функціонал**

#### Нові можливості:
- ✅ **Темна тема** (toggle в header, зберігається в localStorage)
- ✅ **Мультимовність** (UA/EN), також зберігається
- ✅ **Share API** (navigator.share для мобілей)
- ✅ **JSONP запити** замість CSV (швидше, менше CORS помилок)
- ✅ **Лайтбокс галерея** з навігацією стрілками (← →)
- ✅ **Таблиця донатів** замість timeline (компактніше)
- ✅ **Покращена мобільність** (адаптивні сітки на 720px та 430px)

#### Видалені:
- ❌ Табхерування платежів → замінено на grid карт
- ❌ Старий CSV парсинг → нова Google Sheets Query API
- ❌ Toast копіювання → можна додати назад
- ❌ Список донатів з лінією (timeline) → таблиця

### 5. **Google Sheets структура**

#### Нові вкладки:
1. **Texts** (замість "Опис")
   - Підтримує мовні ключі з суфіксом `_ua` та `_en`
   - Може мати глобальні ключі без мови (fallback на UA)

2. **Donations** (замість "Supporters")
   - `Date | Amount | Payment System | Country_UA | Country_EN`
   - Більш гнучкий парсинг з пошуком колонок

#### Приклад структури:
```
Texts:
A1: header_ua          | B1: Збір на мінівен...
A2: header_en          | B2: Fundraiser for minivan...
A3: paragraph_ua       | B3: Старий мінівен...
A4: title1_ua          | B4: Для чого потрібен...
```

### 7. **CSS змінювання**

#### Нова система:
- CSS змінні для всіх кольорів `:root`
- Темна тема перевизначає змінні у `body.theme-dark`
- Gradient фон замість плоского кольору
- Використання CSS `clamp()` для responsiveness

#### Responsive точки:
- `≥ 1180px`: Desktop
- `980px - 1179px`: Середній (реорганізація сітки)
- `720px - 979px`: Таблет (один стовпець)
- `≤ 430px`: Мобіль (дуже компактно)

## 🎯 Переваги fresh-design

### Юзер-ориєнтовані:
1. **Темна тема** - комфортніше вночі
2. **Мультимовність** - одна сторінка, 2 мови
3. **Таблиця вмість timeline** - легше скануються великі числа
4. **Галерея з навігацією** - більш інтерактивно
5. **Світліший дизайн** - більш сучасний, менш похмурий

### Розробник-ориєнтовані:
1. **Чітка архітектура** - легче додавати нові вкладки
2. **JSONP замість CSV** - менше CORS проблем
3. **Локалізація вбудована** - не потребує окремого файлу
4. **CSS змінні** - легко змінювати тему
5. **README.md** - документація (замість README.txt)
